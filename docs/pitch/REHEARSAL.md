# Chhat — Night-Before Rehearsal Checklist

Final: 4th International AI Championship, FAST-NUCES Lahore. Demo must NEVER fail.

## 1. Machine
- [ ] Laptop fully charged + charger in the bag
- [ ] Phone hotspot tested and working (backup internet)
- [ ] Venue WiFi tested from the stage position if possible
- [ ] Screen brightness max, notifications OFF, sleep disabled
- [ ] Browser: one clean window, only the Chhat tab + this checklist

## 2. Demo readiness
- [ ] Open the app, run ONE full live analysis end-to-end
- [ ] Open `golden-demos.json` route — confirm 10 demos load
- [ ] Practice the golden fallback: disconnect WiFi, confirm "Load golden demo" appears and renders the full report with ZERO backend
- [ ] Pick your 2 hero golden demos (recommend: Packages Mall Lahore 88/100, Pearl Continental Karachi 93/100)
- [ ] Decide: live address attempt first, or straight to golden? (Golden-first is the safe play.)

## 3. Timing (60 seconds)
- 0:00–0:10 — the hook: "Type any Pakistani address, get your roof's solar score."
- 0:10–0:35 — paste address → parsed chips → confirm pin → report renders (score ring, panels, quote)
- 0:35–0:50 — the numbers: "9.9 kW, Rs 1.42M, pays back in 2.4 years — sized for the net-billing era"
- 0:50–1:00 — the closer: "Our own trained model reads the roof. No paperwork, no site visit."

## 4. If things break (say these exact lines)
- **API fails:** "And if the internet dies — which in Pakistan, it does — watch this." → Load golden demo.
- **Projector fails:** talk through the printed one-pager (print 5 copies tonight).
- **Question you can't answer:** "Great question — that's exactly what our partner validation data will answer. I'll get you the number after the demo."
- **"Isn't this just the Google API?"** "Google sells raw satellite data. Nobody turns it into a Pakistani rooftop quote, nobody models net billing, nobody parses Nishat Colony addresses. We built the product layer — and trained our own address parser and roof segmenter."

## 5. Bag checklist
- [ ] Laptop + charger
- [ ] Phone + hotspot data topped up
- [ ] HDMI/USB-C adapter (bring your own — never trust the venue's)
- [ ] 5 printed one-pagers
- [ ] Water

## 6. Morning of
- [ ] Re-run one golden demo load (30 seconds)
- [ ] Breathe. You built the thing. Now show it.
